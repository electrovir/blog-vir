Search runs entirely in the browser against a pre-built index, so there is no server to deploy.

<!--truncate-->

## The index

Each heading in each post becomes its own index entry. Searching for a word that only appears under
one heading takes you straight to that heading rather than to the top of the post.

## Tags

Tags get their own pages. Every tag on a post is a link, and the tag list page shows how many posts
carry each one.
